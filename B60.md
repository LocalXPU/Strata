# Strata on two Arc Pro B60 (LocalXPU fork)

This branch is upstream Strata `6f32ec0` with two fixes in `sycl/` and a few doc changes. It ran Coder IQ1_M and Flash-Next IQ2_XS on two Intel Arc Pro B60 24 GB cards. What differs from upstream is listed in [the last section](#what-differs-from-upstream).

Measured on: 2x Arc Pro B60 (`8086:e211`), Ryzen 5 5600, 64 GB RAM, Ubuntu 24.04, kernel 6.17 (`xe`), NEO 26.09.37435.12, oneAPI DPC++ 2026.1.1 and oneMKL 2026.1.0.

| Model | Cards | Decode | Prompt (2,129 tokens) |
| --- | --- | --- | --- |
| Coder IQ1_M | 2x B60, `--layer-split 24` | 56.6 tok/s | 428 tok/s |
| Flash-Next IQ2_XS | 2x B60, `--layer-split 25` | 58.6 to 61.3 tok/s | 436 tok/s |
| Coder IQ1_M | 1x B60, 4,042 of 12,288 experts in RAM | 11.9 tok/s | not measured at this size |

Short prompts, 8,192-token context, greedy, MTP on, one request at a time. Details and per-request numbers:
[docs/INTEL_ARC.md](docs/INTEL_ARC.md) and `bench/results/2026-10-04-community-2x-arc-pro-b60/`.

## Build

```sh
sudo apt install intel-oneapi-compiler-dpcpp-cpp intel-oneapi-mkl-devel intel-ocloc ninja-build cmake
source /opt/intel/oneapi/setvars.sh        # not in a shell with `set -u`: it stops at OCL_ICD_FILENAMES
cmake -S sycl -B build-sycl-aot -G Ninja -DCMAKE_C_COMPILER=icx -DCMAKE_CXX_COMPILER=icpx \
      -DSTRATA_SYCL_AOT=bmg-g21 -DSTRATA_GGML_DIR=/path/to/llama.cpp-3cf0325
nice -n 19 cmake --build build-sycl-aot -j4 -- -k 0
```

`bmg-g21` is the B60 (and B580/B570). The AOT build took about 15 minutes at `-j4`. `STRATA_GGML_DIR` points at the llama.cpp checkout upstream pins
(`setup.py` fetches it); without it CMake clones ggml. `sycl-ls` should list both cards as `Intel(R) Arc(TM) Pro B60 Graphics 20.1.0`.
A normal user needs to be in the `render` group, or `sycl-ls` shows only the CPU.

## Models

`setup.py`'s own steps work without Docker: download the shards, pack with `tools/iq_pack.py`, fetch and pack the MTP layer with
`tools/mtp_fetch.py`, `mtp_pack.py` and `mtp_rt.py`. `setup.sh --backend sycl` needs Docker and was not used.

## Run on two cards

`--layer-split` needs `--serve`, so use the server. Write a config (the one used for Coder IQ1_M; for IQ2_XS use the IQ2_XS pack and shards,
`data/expert-profile.bin` and `"--layer-split", "25"`):

```json
{"engine": "strata", "exe": "/path/to/strata-native.sh", "cwd": "/path/to/Strata",
 "tokenizer": "/path/to/packs/coder-iq1_m/tokenizer", "model_name": "coder-iq1_m", "backend": "sycl",
 "args": ["--pack", "/path/to/packs/coder-iq1_m",
          "--native", "/path/to/Qwen3.8-Flash-Next-GSQ-RCO-IQ1_M-00001-of-00002.gguf",
          "--ple-gguf", "/path/to/Qwen3.8-Flash-Next-GSQ-RCO-IQ1_M-00002-of-00002.gguf",
          "--expert-profile", "data/expert-profile-coder.bin", "--expert-cache", "auto", "--stream-experts",
          "--prefill", "auto", "--spec", "4", "--spec-min-p", "0.5", "--mtp", "/path/to/mtp/rt",
          "--max-context", "8192", "--kv", "int8", "--vram-reserve-mib", "1536", "--no-prefill-borrow",
          "--layer-split", "24"],
 "env": {"ONEAPI_DEVICE_SELECTOR": "level_zero:0,1", "SYCL_CACHE_PERSISTENT": "0", "STRATA_MIRROR_MIB": "6144",
         "STRATA_VERIFY_DEVICE_PLAN": "1", "STRATA_STAGE_TRIM": "1", "STRATA_VERIFY_NO_HOST": "1"}}
```

`strata-native.sh` stands in for `sycl/serve/strata-sycl.sh` (which runs the engine in Docker). It is three lines:

```sh
#!/usr/bin/env bash
source /opt/intel/oneapi/setvars.sh >/dev/null 2>&1      # setvars must not write to stdout: the serve protocol is lines on it
export SYCL_CACHE_PERSISTENT=0 ZES_ENABLE_SYSMAN=1 STRATA_VERIFY_DEVICE_PLAN=1 STRATA_STAGER_THREADS=${STRATA_STAGER_THREADS:-12}
exec /path/to/Strata/build-sycl-aot/strata "$@"
```

Then:

```sh
python3 sycl/serve/server_intel.py --engine strata --config strata-b60.json --port 8085
curl -s localhost:8085/v1/chat/completions -H 'content-type: application/json' \
  -d '{"messages":[{"role":"user","content":"Write a Python function that returns the n-th Fibonacci number"}],"max_tokens":256,"chat_template_kwargs":{"enable_thinking":false}}'
```

Choosing K for `--layer-split K` (the first layer on the second card): read the startup log of a first run for the per-card cache sizes, then pick K so the
experts of each half fit. IQ2_XS needs 17.75 GB of experts per card at K=24; card 1 had room at K=25. Leave 1.5 GB free on each card (`--vram-reserve-mib 1536`).

- `STRATA_VERIFY_NO_HOST=1` is only valid when the startup log says `100% of the experts resident` on both cards. Both runs above did.
  The first start of each model had it unset; restart with it set after reading the log.
- On a split, set `STRATA_MIRROR_MIB` low (0): the pinned mirror it allocates is not used, and the line `N experts are neither in VRAM nor mirrored` counts the other card's layers.
- `STRATA_STAGE_TRIM=1` makes each card load only its own layers' dense weights.

## Run on one card

With part of the experts mirrored in RAM (Coder IQ1_M, 4,042 of 12,288), the per-layer path runs. It needs the ring-wait fix below and decodes at 11.9 tok/s:

```sh
ONEAPI_DEVICE_SELECTOR=level_zero:0 STRATA_MIRROR_MIB=8192 /path/to/strata-native.sh --pack ... (arguments as above, without --layer-split) \
    --tokens "$IDS" --max-new 128 --greedy
```

Most of that time is the GPU waiting for the host's flag: `wait for rings` is about 3.9 ms per layer and scales with the spin bound in
`sycl/include/strata/sycl_doorbell.hpp` (`kSpinMax`, 25.1 tok/s at 2,000, 28.4 at 200). Lowering it risks proceeding before a slow host answers, so it is left alone.

## What differs from upstream

- `sycl/` compiles at `6f32ec0` (the port's copies of `session.cpp/.hpp` and `native_dense.cpp` follow #626 and #559).
- `sycl/src/core/session.cpp` and `verify.cpp` keep `cudaStreamQuery`'s answer in the per-layer ring wait. The port turned it into a value that is always 0,
  so any ring wait over 2 ms was reported as `never rang (graph finished)`. Layer 15 of the Coder on one B60 was the first layer to take longer.
- `sycl/setup_intel.py` knows PCI id `e211` as the Arc Pro B60.
- `docs/INTEL_ARC.md` and `docs/COMMUNITY_BENCHMARKS.md` have the B60 rows; `bench/results/2026-10-04-community-2x-arc-pro-b60/` has the report.

Nothing else in the engine is changed. These are proposed upstream as separate pull requests.
